## 项目简介

这是一个基于 Django + Vue 3 的生态养殖管理系统，提供用户认证、养殖档案、生产管理、疾病处理、统计分析和质量溯源等功能。

### 主要角色

- 管理员
- 养殖户
- 兽医
- 公众

### 主要功能

- 用户认证与角色权限管理
- 养殖户实名认证
- 养殖区域与批次管理
- 投喂与库存管理
- 疾病上报与协同处理
- 疫苗接种记录
- 生产统计分析
- 批次质量溯源
- 二维码溯源查询

## 快速开始

### 1. 创建数据库

```sql
CREATE DATABASE ecological_breeding_system DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 2. 导入数据库

```bash
mysql -uroot -p ecological_breeding_system < database/ecological_breeding_system.sql
```

### 3. 安装后端依赖

```bash
pip install -r requirements.txt
```

### 4. 启动 Django

```bash
python manage.py migrate
python manage.py runserver
```

### 5. 安装并启动前端

```bash
cd frontend
npm install
npm run dev
```

具体环境变量和部署配置请参考项目中的 `.env.example` 及相关配置文件。
